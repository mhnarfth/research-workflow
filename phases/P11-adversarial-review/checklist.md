## Setup
- [ ] **Fresh chat, zero project context** — not inside the paper's LLM project
- [ ] Only the PDF attached (plus `PATTERNS.md` and/or an external review)
- [ ] Run **2–3 times** with different framings, each in its own chat
- [ ] Any external review triaged in its **own** fresh chat, not one that has
      already produced an attack list

## Output
- [ ] Attack list is ranked by severity
- [ ] Each attack points at a specific section, claim, figure, or number
- [ ] I have suggested wording for every "weaken" and every "concede"

## Triage — my decision, recorded in `DECISIONS.md`
- [ ] Every attack has a disposition
- [ ] Anything that **invalidates a claim in `CLAIMS.md`** → back to code.
      Non-negotiable
- [ ] Anything that weakens a claim → wording softened in the draft
- [ ] Anything needing an experiment I don't have → conceded in Limitations
- [ ] Framing issues → fixed in text
- [ ] Next-paper questions → captured for `NOTES.md` extensions

## Reality check
- [ ] If I'm dismissing an attack, I can say **why** — not just that it's
      inconvenient this close to the deadline
