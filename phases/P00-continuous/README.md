# P00 — Continuous

**No chat. No phase output. Background habits that run always.**

These are what make P01 cheap. A deadline appearing shouldn't mean
brainstorming cold — it should mean picking from ten pre-thought ideas.

## The habits

| Habit | Where it lands |
|---|---|
| Zotero collects everything you read, always | Zotero + `LEDGER-reading.md` |
| Drop ideas in unfiltered the moment they occur | `research-index` → idea backlog |
| Update a paper's row when its status changes | `research-index` → paper tracker |
| Log peer reviews you accept | `research-index` → paper tracker |
| Add people after conferences | `research-index/CONTACTS.md` |
| Register a dataset the first time you touch it | `research-index` → dataset registry |

**Peer reviewing is not a distraction.** It is the best available way to learn
what reviewers actually punish, and it feeds `reviews/PATTERNS.md`.

## The yearly block

Nothing triggers these, which is exactly where systems rot. One recurring
calendar entry, about an hour:

- Distill `reviews/PATTERNS.md` from accumulated reviews
- Review the rejection log — what do you consistently reject, and what does
  that say about what you should go learn?
- Prune the idea backlog
- Check `NOTATION.md` for drift across papers
- Refresh `PROFILE.md`
- Mirror all repos to GitLab
- Review `LEDGER-tooling.md` — adopt the next one

## Why there's no opening.md

This phase has no chat. It's a checklist you live by, not a session you run.
