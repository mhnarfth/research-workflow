# P14 — Checklist

## Both paths
- [ ] I waited a day or two before working the reviews
- [ ] Every point triaged: correct / partially / misreading / out of scope
- [ ] Every disagreement is backed by evidence, not assertion
- [ ] Reviews archived to `research-index/reviews/<venue><year>.md` with my
      response and what changed
- [ ] Any pattern noticed against previous papers is flagged for `PATTERNS.md`

## Path A — rebut / revise
- [ ] Response is point-by-point and non-defensive
- [ ] `CLAIMS.md` "As submitted" used, not the planned version
- [ ] Anything conceded appears in the revised Limitations
- [ ] Advisor sees the finished response

## Path B — rejected
- [ ] Real objections separated from noise
- [ ] Next venue chosen **from the ladder in `VENUE.md`**
- [ ] If choosing off-ladder, I recalibrated rather than improvised
- [ ] Schedule recomputed for the new deadline
- [ ] Required changes listed, with any that need code flagged
- [ ] **A date is on the calendar for the resubmission.** A rejected paper
      sitting idle is the failure mode this phase exists to prevent
