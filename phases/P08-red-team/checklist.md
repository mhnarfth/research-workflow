# P08 — Checklist

Before firing:

- [ ] The primary result exists — this is a real finding, not a fragment
- [ ] Defensive work has **not** started, so there's still time to act
- [ ] This is a **separate chat**, not my execution chat

Before leaving:

- [ ] Attack list is prioritized, not a flat list
- [ ] Every attack has a proposed experiment or an honest "weaken the claim"
- [ ] Aggregates checked: outlier-driven? mean vs. median? between-group
      artifact masquerading as a correlation?
- [ ] `STAGE-PLAN.md` updated with any new defensive stages
- [ ] `DECISIONS.md` records what changed and why, tagged `[red-team]`
- [ ] **Delta paragraph pasted into the live execution chat** — editing the file
      does not update a chat that's holding the old version
- [ ] Any scope advice noted; the decision is recorded as mine

Later:

- [ ] If results change the picture substantially, re-fire as `P08-redteam-2`
