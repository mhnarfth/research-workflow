# P05 — Checklist

Before leaving this phase:

- [ ] I wrote my own RQs and contributions **before** the chat weighed in
- [ ] Every RQ is answerable with the data and budget in `FEASIBILITY.md`
- [ ] Every contribution has stated evidence requirements **and** something
      that would falsify it
- [ ] Contributions are phrased in this venue's idiom
- [ ] **Figure sketches exist** — each with what it shows and what it would
      look like if the claim were false
- [ ] **Table sketches exist**
- [ ] Draft abstract written, dated, and marked as aspirational
- [ ] Notation checked against `NOTATION.md`; no accidental second symbol for
      something already named in a prior paper
- [ ] The one-sentence claim is written down and I can say it out loud

The figure and table sketches are the contract with P06. If they're vague, the
pipeline has no target and you'll generate twice what you ship.
