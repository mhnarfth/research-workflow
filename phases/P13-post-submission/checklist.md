# P13 — Checklist

Do all of this the same day you submit. It takes under an hour and it is the
difference between resuming in three years and reconstructing from nothing.

- [ ] `git tag <venue><year>-submitted` and `git push --tags`
- [ ] `pip freeze > requirements-frozen.txt`, committed
- [ ] `NOTES.md` finished **while fresh** — decisions, bugs, stability, headline
      numbers with source files
- [ ] `CLAIMS.md` has an `## As submitted` section, frozen
- [ ] Extension ideas: paragraphs in `NOTES.md`, one line each in the index
      backlog
- [ ] Collection note written
- [ ] Index row updated: status, venue, date, repos, key result, grants
- [ ] **Retro chat run** — fresh chat, `cat docs/handoffs/*-meta.md` as input
- [ ] Retro output appended to `research-workflow/LEDGER-improvements.md`
- [ ] Preprint only if `VENUE.md` permits it — and the default is to wait for
      acceptance
- [ ] Everything committed and pushed
